# DIO
# Plano de Estudos: Transição para Engenharia de Dados (30 Dias)
## 🎯 Objetivo

Realizar a transição de carreira de **Análise de Dados** para **Engenharia de Dados** (com foco inicial em **Analytics Engineering**) em **30 dias**, mantendo uma rotina consistente de **1 hora diária**.

O plano aproveita sua bagagem analítica atual para construir uma base técnica sólida em **modelagem**, **versionamento**, **transformação de dados** e **nuvem**, culminando em um **mini-projeto prático de portfólio**.

---

## 🗺️ Visão Geral das 4 Semanas

| Semana | Dias | Foco Principal | Entregável / Marco |
| :--- | :--- | :--- | :--- |
| **Semana 1** | 1 a 7 | SQL Avançado, Modelagem Dimensional e Git/GitHub | Consultas avançadas, base conceitual Kimball e primeiro repositório no GitHub |
| **Semana 2** | 8 a 14 | Transformação de Dados com dbt (Data Build Tool) | Projeto modular (`staging`, `intermediate`, `marts`), testes nativos e documentação `.yml` |
| **Semana 3** | 15 a 21 | Python Voltado para Dados | Manipulação de CSV/JSON/Parquet com Pandas e extração via API com `requests` |
| **Semana 4** | 22 a 30 | Data Warehouse, Cloud e Projeto Integrador | Pipeline completo: Python (extração) → BigQuery/Snowflake → dbt → GitHub documentado |

## 🚀 Como Usar no Dia a Dia

1. **Alinhamento inicial**: Revise o documento **Transição** (também presente nesta pasta em `Transição.docx` / Google Drive) para manter foco nos 5 pilares que conectam Análise de Dados à Engenharia de Dados.
2. **Repositório dedicado**: Crie um repositório no GitHub (ex.: `jornada-engenharia-dados`) para versionar seus scripts, modelos e anotações ao longo das 4 semanas.
3. **Rotina diária (1h/dia)**:
   - Consulte o bloco do dia em [cronograma.md](./cronograma.md).
   - Acesse o material correspondente em [recursos.md](./recursos.md).
   - Registre aprendizados, comandos e dúvidas no arquivo da semana em `anotacoes/`.
4. **A cada nova semana**: Duplique [anotacoes/semana-01.md](./anotacoes/semana-01.md) para `semana-02.md`, `semana-03.md` e `semana-04.md`.
